## 6. Live host smoke — ESPHome voice satellite (SC-001 / FR-020)

This is the binding human check.

### Hardware

- A Home Assistant Voice Preview Edition device (or equivalent —
  M5Stack Atom Echo flashed with ESPHome's voice-satellite YAML).
- Wi-Fi on the same LAN as the AIVG gateway host.

### Configure the device's ESPHome YAML

```yaml
# device.yaml — minimal config to point at AIVG instead of HA
api:
  password: !secret aivg_api_key   # the key generated by `aivg device adopt`
  reboot_timeout: 0s

# Point at AIVG, not Home Assistant:
external_components:
  - source: github://esphome/esphome@2024.6.0
    components: [api, voice_assistant]

voice_assistant:
  microphone: my_mic
  speaker: my_speaker
  noise_suppression_level: 2
  auto_gain: 30dBFS
```

(Exact YAML varies by board; the **only AIVG-specific bit** is
pointing `api:` at the AIVG host's IP via your network's mDNS /
DHCP — ESPHome's existing "set the IP in the boot logs" works.)

### Adopt the device

```bash
# On the AIVG host, generate the per-device API key:
aivg device adopt voice-kitchen-1 --transport esphome_api
# → prints the generated API key; paste into the device YAML
#   and reflash, OR set it via ESPHome's web UI.
```

### Run the turn

1. Wait for the device to connect (`aivg list` shows it with
   `transport: esphome_api`, `state: idle` within 5 s).
2. Say the device's wake-word (or press its hardware button).
3. Speak: "What time is it?"
4. The device's STT_START indicator (LED, screen) lights up.
5. Release / stop speaking.
6. Gateway log (`~/.hermes/logs/gateway.log`) shows the same
   `session opened → transcribed → turn complete` shape as a
   WebRTC turn, with `source: "esphome"`.
7. The reply audio plays through the device's speaker.

**Expected**: full voice turn completes within 30 seconds wall-clock
(SC-001). The Hermes agent's actual reply varies (it's a real LLM)
but the turn-completion semantics are byte-identical to WebRTC.
