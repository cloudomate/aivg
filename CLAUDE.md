Feature 021 adds a **gRPC bidirectional-streaming transport** for native satellites as an additive sibling under `aivg_core.transports.grpc/` (mirrors the 017 `transports.esphome/` pattern). **Phase 1** moves the per-session **audio plane** off WebRTC onto an `Audio.Stream` gRPC call (mic PCM up; synthesized audio + transcripts + turn events down) — killing the ICE/DTLS/SCTP "stuck connecting" field failures (upstream bug 5). **Phase 2** moves the **management/control plane** off `/satellite/ws` onto a separate gRPC `Management` service. Reuses the `MediaTransport` Protocol + canonical `Session` seam verbatim (no `platforms/` or `webrtc/session.py` change in Phase 1). WebRTC stays for browser satellites; transport chosen by capability negotiation. Canonical `.proto` at repo-root `proto/aivg/satellite/v1/` (vendored by `aivg-devices` for the C++ client). **Recorded Principle III deviation** (III names WebRTC voice + WS control; intent preserved, amendment recommended). New runtime dep `grpcio` (proposal's "already present" claim is false). Contract envelope bumps `0.2.0` → `0.3.0` (additive) on opt-in.
