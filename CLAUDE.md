Constitution: v2.0.1. Principle IV: satellite system is agent-platform-agnostic via the `AgentPlatform` plugin seam — feature 013 extended the seam to the deploy layer with `SetupCapability`; feature 014 ships `@aivg/sat-sdk` (TypeScript) as the first satellite-side client SDK; feature 015 closed the runtime side of the seam; feature 017 adds the ESPHome native API as an additive transport so any existing ESPHome voice satellite (Home Assistant Voice PE, M5Stack Atom Echo, custom ESP32 firmware) talks to AIVG with no client-side code from us.
